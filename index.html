NestNotes – Flat Sharing Platform

NestNotes is a full-stack web application developed to simplify the process of finding shared accommodation and connecting property owners with potential tenants. CloudPath Sentinel – Cloud Security & Attack-Path Analyzer

CloudPath Sentinel is a security analysis tool developed to uncover hidden privilege escalation paths and attack chains within cloud environments.

The platform models a cloud account as a directed graph of identities, permissions, and resources, then traverses it to discover how a low-privilege entry point can chain through IAM roles, misconfigured policies, and exposed resources to reach high-value targets. Includes read-only ingestion, blast-radius calculation, risk severity scoring, and interactive graph exploration.

Directed graph modelling (NetworkX)
Read-only cloud configuration ingestion
Attack-path & privilege escalation detection
Interactive Streamlit & PyVis dashboard
Python NetworkX Boto3 (AWS SDK) Typer (CLI) Streamlit PyVis Docker IAM Security

IntelliOps – AI-Powered Autonomous IT Operations & Root Cause Analysis Platform

IntelliOps is an AI-powered IT operations and monitoring platform designed to help organizations monitor application performance, detect system failures, identify potential root causes, and automate incident analysis.
