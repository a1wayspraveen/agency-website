3. CloudPath Sentinel – Cloud Security & Attack-Path Analyzer

CloudPath Sentinel is a security analysis tool developed to uncover hidden privilege escalation paths and attack chains within cloud environments.

The platform models a cloud account as a directed graph of identities, permissions, and resources, then traverses it to discover how a low-privilege entry point can chain through IAM roles, misconfigured policies, and exposed resources to reach high-value targets such as admin credentials or sensitive data stores.

Users can ingest their cloud configuration via read-only API access, visualize the resulting relationship graph, and receive ranked findings based on real-world risk—prioritising paths that start from public entry points and end at sensitive resources. Each finding highlights the exact sequence of permissions that enables the escalation, making the attack path easy to understand and remediate.

The project is currently under active development, with the core graph engine, pathfinding logic, and risk scoring engine being built out first, followed by an interactive visualization dashboard.

Key Features

· Read-only cloud configuration ingestion (IAM users, roles, policies, EC2, S3).
· Directed graph modelling of identities, permissions, and resources.
· Automated attack-path and privilege-escalation detection.
· Blast-radius calculation for compromised identities.
· Risk-based severity scoring and prioritisation of findings.
· Visualisation of attack chains with highlighted permission edges.
· Detection of public entry points leading to sensitive resources.
· Policy JSON normalization and wildcard handling.
· CLI-based scanning for quick assessments.
· Interactive dashboard for graph exploration.
